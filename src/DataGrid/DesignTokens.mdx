# Design Tokens

The pipeline: **Figma variables → CSS custom properties → component styles.**
Every token in the Figma file's `Accounting` and `Data Grid / Semantic` collections
is mirrored in [`tokens.css`](?path=/docs/data-grid-datagrid--docs) with its Figma
name preserved as a comment, and the grid consumes only these properties — never
raw values.

**Every value on this page is read live from the running CSS** at render time
(`getComputedStyle`), not hand-typed — so this page cannot drift from the code.
The Figma file's *Spec and M3 Audit* page remains the canonical token
documentation (alias chains, M3 mappings, audit notes); this page proves the
tokens are wired into working code.

## System palette (sys tokens)

The `Schemes/*` tokens the grid consumes, from the Accounting collection
(Light mode). The Figma matrix additionally documents a few scheme tokens the
grid does not consume directly as CSS (`Schemes/Outline`, `Schemes/Secondary`,
`Schemes/Surface Dim`) — those appear inside Figma component internals only,
so they have no custom property here by design.
